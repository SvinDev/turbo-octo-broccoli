# Nyxian

iOS-приложение для розыгрыша друга.

1. На старте: название **Nyxian**, подпись «@pablofskyyy x @Chekush671 external mod menu for “standoff2” for iOS 17.0-26.0.1», модель телефона, версия iOS, «Поддерживаемые iOS: 18.0 – 27.2+» и кнопка **«Запуск»**. На iOS ниже 18 статус — «Совместимо · локальный патч».
2. После «Запуска» — фейковая установка «мод-меню» примерно на 1,5 минуты: проценты, подвисания (на 8 %, 31 %, 51 %, 66 %, 84 %), этапы **1. Поиск → 2. Загрузка → 3. Установка → 4. Проверка** и лог как у чита (поиск процесса Standoff2, инжект dylib, обход античита, модули Aimbot/Wallhack/ESP…). На iOS ниже 18 в логе появляется «локальный патч применён» — по времени ничего не добавляется.
3. На 95 % «автопатч» не срабатывает, и открывается экран **«Нужно вручную сделать патч»**: консоль пишет «Ожидание патча от пользователя…» и просит подтвердить патч кнопками громкости. Шкала показывает реальную громкость телефона; в тот же миг, когда она доходит до 50 %, включается песня и котик — без кнопок и задержек (даже если консоль ещё печатает). Скрытый запасной выход — удержать консоль 2 секунды.
4. Дальше на чёрном экране крутится котик и по кругу играет песня.

## Песня

Лежит в `Nyxian/Music/HOLY_GRAIL_CAVALLI_speed_up.mp3` (ускорена в 1,5 раза вместе с тоном, как speed up-версии, первые 2 секунды обрезаны). Приложение играет первый аудиофайл (mp3/m4a/aac/wav) из этой папки — чтобы заменить песню, просто подмени файл.
Звук идёт даже при включённом беззвучном режиме.

## Сборка

**Через Xcode (нужен Mac):** открой `Nyxian.xcodeproj`, в *Signing & Capabilities* выбери свою команду (подойдёт бесплатный Apple ID), подключи iPhone и нажми Run.

**Без Mac:** при каждом пуше в `master` GitHub Actions собирает неподписанный `Nyxian.ipa` (вкладка *Actions* → последний запуск → артефакт *Nyxian*). Скачай, распакуй zip и установи `.ipa` через Sideloadly, AltStore или аналог — они подпишут его твоим Apple ID.

Минимальная iOS для установки — 16.0.
