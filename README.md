# Nyxian

iOS-приложение для розыгрыша друга.

1. На старте: название **Nyxian**, модель телефона, версия iOS, «Поддерживаемые iOS: 18.0 – 27.2+» и кнопка **«Запуск»**.
2. После «Запуска» — фейковая установка примерно на 1,5 минуты: проценты, подвисания (на 8 %, 31 %, 51 %, 66 %, 84 % и, конечно, на 99 %), этапы **1. Поиск → 2. Загрузка → 3. Установка → 4. Проверка** и лог как у настоящего установщика.
3. В конце на чёрном экране крутится котик и по кругу играет песня.

## Песня

Файла с песней в репозитории нет. Положи mp3 (или m4a/aac/wav) в папку `Nyxian/Music/`, например
`Nyxian/Music/Arlekin40000 - Holy Grail Cavalli.mp3`. Приложение играет первый найденный там аудиофайл.
Звук идёт даже при включённом беззвучном режиме, но громкость телефона должна быть поднята.

## Сборка

**Через Xcode (нужен Mac):** открой `Nyxian.xcodeproj`, в *Signing & Capabilities* выбери свою команду (подойдёт бесплатный Apple ID), подключи iPhone и нажми Run.

**Без Mac:** при каждом пуше в `master` GitHub Actions собирает неподписанный `Nyxian.ipa` (вкладка *Actions* → последний запуск → артефакт *Nyxian*). Скачай, распакуй zip и установи `.ipa` через Sideloadly, AltStore или аналог — они подпишут его твоим Apple ID.

Минимальная iOS для установки — 16.0.
