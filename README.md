# Nyxian

iOS-приложение для розыгрыша друга.

1. На старте: название **Nyxian**, модель телефона, версия iOS, «Поддерживаемые iOS: 18.0 – 27.2+» и кнопка **«Запуск»**.
2. После «Запуска» — фейковая установка примерно на 1,5 минуты: проценты, подвисания (на 8 %, 31 %, 51 %, 66 %, 84 %), этапы **1. Поиск → 2. Загрузка → 3. Установка → 4. Проверка** и лог как у настоящего установщика.
3. На 95 % «автопатч» не срабатывает, и открывается экран **«Нужно вручную сделать патч»** с фейковой видеоинструкцией и просьбой прибавить звук (шкала показывает реальную громкость телефона, нужно от 30 %). Первое нажатие на видео при тихом звуке — ещё раз просит прибавить, второе пускает в любом случае.
4. После «загрузки видео» на чёрном экране крутится котик и по кругу играет песня.

## Песня

Лежит в `Nyxian/Music/HOLY_GRAIL_CAVALLI_speed_up.mp3` (ускорена в 1,5 раза вместе с тоном, как speed up-версии). Приложение играет первый аудиофайл (mp3/m4a/aac/wav) из этой папки — чтобы заменить песню, просто подмени файл.
Звук идёт даже при включённом беззвучном режиме.

## Сборка

**Через Xcode (нужен Mac):** открой `Nyxian.xcodeproj`, в *Signing & Capabilities* выбери свою команду (подойдёт бесплатный Apple ID), подключи iPhone и нажми Run.

**Без Mac:** при каждом пуше в `master` GitHub Actions собирает неподписанный `Nyxian.ipa` (вкладка *Actions* → последний запуск → артефакт *Nyxian*). Скачай, распакуй zip и установи `.ipa` через Sideloadly, AltStore или аналог — они подпишут его твоим Apple ID.

Минимальная iOS для установки — 16.0.
